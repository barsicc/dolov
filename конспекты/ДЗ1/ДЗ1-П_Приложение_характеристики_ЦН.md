## Ключевое
- ⭐ **Все графики — Q–H, Q–N, Q–η** (на воде, ρ = 1000 кг/м³). Кривых NPSH/Δh, допускаемой высоты всасывания, нескольких D₂ — **нет ни на одном рисунке**; **D₂ нигде не указан**.
- ⭐ **Подача Q везде в м³/сут** (перевод: Q[м³/с] = Q[м³/сут] / 86 400). Напор H — м; мощность N — кВт; КПД η — %.
- ⭐ **Отечественные насосы (рис. 2.10–2.48, 4.x)** — характеристика на **100 ступеней**, n = 2910 об/мин (Новомет ЭЦН4-20 — 2820). Напор сотни метров, N единицы кВт.
- ⭐ **Зарубежные (REDA, Centrilift, ESP, ODI)** — на **1 ступень**: H = 1,5…7 м, N = 0,03…0,15 кВт (≈ 30…150 Вт); n = 2915/2916/2917 (ESP — 3500). **Temtex** — 100 ступеней, n = 2820.
- ⭐ У многих рисунков **шкала N — отдельная короткая шкала справа**, не совпадающая с сеткой H (например, 2,5–5,0–7,5–10 кВт на участке нижней части поля); перед снятием значений N отметить по ней цену деления. Шкала η часто тоже вынесена (иногда η = H/10 по сетке).
- На рисунках отмечена «Рабочая часть» (рекомендуемый диапазон подач) — штриховкой/вертикальными линиями.
- Все 23 рисунка вариантов **найдены** (рис. 4.5 — у вариантов 6 и 8).

## Как пользоваться при выполнении ДЗ
1. Найти свой рисунок в таблице вариантов → открыть `рисунки/ДЗ1-П/стрNNN.jpg` (при нехватке чёткости — рендер крупнее:
   `pdftoppm -r 220 -jpeg -f N -l N -singlefile "03_ДЗ/ДЗ-1/ДЗ1-П_Приложение_характеристики_ЦН.pdf" /tmp/zoom`).
2. Снять 7–10 точек от Q = 0 до конца кривой H (по вертикальным линиям сетки): H, N, η. Перевод: Q[м³/с] = Q[м³/сут]/86 400; N[Вт] = 1000·N[кВт].
3. Проверка снятых точек: $N = \dfrac{\rho g Q H}{\eta}$ должна примерно совпадать с кривой N (для одноступенчатых — с N одной ступени).
4. Для 100-ступенчатых насосов при желании можно перейти к одной ступени: H₁ = H/100, N₁ = N/100 (η и Q не меняются).
