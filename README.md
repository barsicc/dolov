# dolov — Гидромашины и компрессоры

Материалы курса «Гидромашины и компрессоры» (РГУ нефти и газа им. И.М. Губкина, преп. Долов Т.Р.): лекции, лабораторные, ДЗ, литература — в виде, удобном для работы с Claude.

- **[КАРТА.md](КАРТА.md)** — навигатор: все файлы, темы → конспекты и страницы, каталог рисунков. Реестр обновляется автоматически после каждой загрузки.
- **[ФОРМУЛЫ.md](ФОРМУЛЫ.md)** — все ключевые формулы со ссылками на источник.
- **[конспекты/](конспекты/)** — полные транскрипции с формулами в LaTeX.
- `01_Лекции/`, `02_Лабы/`, `03_ДЗ/`, `04_Литература/` — исходные файлы.
- `рисунки/` — страницы со схемами и графиками.
- **`upload/`** — сюда загружать новые материалы, затем попросить Claude «разбери upload».
