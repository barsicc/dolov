# dolov — Гидромашины и компрессоры

> **Всем ИИ, работающим с репозиторием:** прежде чем отвечать на учебный вопрос, прочитайте [обязательный регламент проверки](AGENTS.md). Не копируйте архивные решения без самостоятельной проверки. Если есть существенные сомнения — обязательно ищите внешние источники, если доступен веб-поиск. Достоверность важнее скорости.

Материалы курса «Гидромашины и компрессоры» (РГУ нефти и газа им. И.М. Губкина, преп. Долов Т.Р.): лекции, лабораторные, ДЗ, литература — в виде, удобном для самостоятельной подготовки и работы с ИИ.

- **[КАРТА.md](КАРТА.md)** — навигатор: все файлы, темы → конспекты и страницы, каталог рисунков. Реестр обновляется автоматически после каждой загрузки.
- **[ФОРМУЛЫ.md](ФОРМУЛЫ.md)** — все ключевые формулы со ссылками на источник.
- **[конспекты/](конспекты/)** — постраничные конспекты лекций и краткие конспекты глав учебника Башты.
- `01_Лекции/`, `02_Лабы/`, `03_ДЗ/`, `04_Литература/` — исходные файлы.
- `рисунки/` — страницы со схемами и графиками.
- **`upload/`** — сюда загружать новые материалы, затем попросить Claude «разбери upload».
