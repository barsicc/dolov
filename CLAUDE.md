# База знаний по курсу «Гидромашины и компрессоры» (экзамен)

Репозиторий — источник знаний для ответов на вопросы по курсу. **Не читай PDF из `upload/`** — это дорого по лимитам.
Всё уже конвертировано в `knowledge/`.

## Как искать ответ (экономно)
1. `knowledge/INDEX.md` — список документов, число страниц, оглавление (где есть).
2. Найди нужное по тексту: `grep -rn -i "ключевое слово" knowledge/*/text/` (маркеры `=== Страница N ===` показывают номер страницы PDF).
3. Прочитай только нужный кусок: `knowledge/<doc>/text/pNNN-MMM.md` (по 10 страниц).
4. **Формулы, графики, схемы, таблицы** в текстовом слое испорчены (греческие буквы и дроби теряются, у Башты OCR-шум). Поэтому для любой формулы/рисунка открой картинку страницы: `knowledge/<doc>/pages/NNN.jpg` (NNN = номер страницы PDF, 3 цифры). Читай только нужные страницы.
5. Ссылайся в ответах на документ и страницу.

## Документы
- `lekcii-1`, `lekcii-2`, `lekcii-3` — конспект лекций Касьянов, Кривенков, Ходырев, Чернобыльский «Гидромашины и компрессоры» (тетради I, II, III: теория гидромашин, гидропередачи, компрессоры).
- `obschie-polozheniya-i-klassifikaciya-protochnyh-mashin` — слайды лекции 1 (общие положения, классификация проточных машин).
- `bashta-gidravlika` — Башта Т.М., «Гидравлика, гидромашины и гидроприводы», 2010 (OCR, текст шумный — сверяйся с картинкой).

## Добавление новых материалов
Пользователь кладёт новые файлы (pdf, docx, pptx…) в `upload/`. Затем:
```
pip install pymupdf        # один раз за сессию
python3 tools/ingest.py    # конвертирует только новое/изменённое, обновляет INDEX.md
```
(`--force` — переконвертировать всё). Результат (`knowledge/`) нужно закоммитить и запушить. Исходники в `upload/` не удалять.
