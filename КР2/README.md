## Опорные обозначения

- $F=\pi D_п^2/4$, $f=\pi d_ш^2/4$, $S$ — ход. За двойной ход односторонний и дифференциальный дают $q=FS$, двусторонний — $q=(2F-f)S$. У дифференциального один такт всасывания и две порции нагнетания. Т2, PDF 16.
- Идеальная подача $Q_и=qn$. Если $q$ в м³ за цикл и $n$ в циклах/с, то $Q_и$ в м³/с. У поршневого вального насоса $n$ — частота двойных ходов. Т2, PDF 33–34.
- Для одновинтового насоса Муано $q=8eDt=4eDT$, $T=2t$. $T$ — шаг обоймы, $t$ — шаг винта, $e$ — эксцентриситет, $D$ — поперечный размер по выноске 8.3 а (ширина обоймы, равная диаметру круглого сечения винта в этой идеализированной геометрии). Т2, PDF 65.
- $\delta_q=(Q_{\max}-Q_{\min})/Q_{\text{ср}}$ сравнивают при заданных фазах и площадях камер. Удвойте $n$ в идеальной модели: абсолютные расходы удвоятся, а $\delta_q$ сохранится. Т2, PDF 35–38.
- $A_{\text{инд}}=p_{\text{инд}}FS$ для одной камеры, $N_{\text{инд}}=A_{\text{инд}}n$. Мощность камер суммируется, работа имеет размерность Дж, мощность — Вт. К индикаторной мощности при переходе к валу добавляются механические потери. Т2, PDF 44–45.

Для схем на бланках А6 и Б6 типы насосов установлены по геометрии. Номера позиций приведены только для учебных оригиналов с читаемой легендой. Для Б10 двусторонний насос — обоснованная интерпретация. Условия сравнения и причины неопределённости приведены в [матрице](АУДИТ.md).
