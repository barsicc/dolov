# upload — входящие

Загружай сюда новые материалы как есть (PDF, DOCX, PPTX, XLSX, фото), с любыми именами.
После загрузки GitHub Action отметит их в `КАРТА.md` как «ожидают разбора».
Затем попроси Claude: **«разбери upload»** — он определит, что это, переименует, разложит по папкам,
сделает конспект с формулами и обновит карту (регламент — в `CLAUDE.md`).
